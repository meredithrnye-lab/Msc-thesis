# Manufacturing 
This folder contains relevant files to the manufacturing process of the soft robotic exoskeleton prototype. 

## Mold Designs
The full prototype requires 4 different mold pieces: 2 for each half of the finger. Each half has a female part and a male part. The naming convention is therefore 

- IX_RHM = Iteration x, Right half male
- IX_RHF = Iteration x, Right half female
- IX_LHM = Iteration x, Left half male
- IX_LHF = Iteration x, Left half female
